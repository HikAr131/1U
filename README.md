# 1U

1U 是一款面向 Windows 玩家的桌面工具：一键优化、三角洲专项、游戏滤镜、通用游戏优化、灵敏度调校、音效增强、玩家社区、系统优化与调校。官网：https://1utool.cn/

## 系统要求

- Windows 10 / Windows 11
- 1U 需要管理员权限运行（安装后会自动以管理员身份启动）

## 使用说明

下载后运行安装包，根据提示完成安装。安装包带有代码签名（签名者：Guangzhou Tianhe District Yiyou Software Development Studio）；如果 Windows SmartScreen 提示，请核对签名者后继续。

## 功能一览

| 模块 | 内容 |
|---|---|
| 一键优化 | 三套官方方案（三角洲·性能优先 / 三角洲·清晰流畅 / 游戏通用），一次配置电源计划、鼠标键盘、N 卡设置与系统基础性能，应用前可逐项取消，执行后留有恢复记录 |
| 三角洲专项 | 粥小工具、改枪码、伪装显卡、模型预设（DLSS / 超分辨率 / 帧生成 / 橡皮泥画质）、内存优化与清理、修复 200 伤害踢、修复更新后卡顿掉帧 |
| 游戏滤镜 | 跨游戏颜色滤镜中心：ICC 预设、动态震动、动态暗部、真饱和度、场景自适应；选好滤镜进游戏自动生效，也可按前台程序单独设置 |
| 通用游戏优化 | 鼠标键盘调校、鼠标直线修正、外置准星、游戏监控、着色器缓存清理、NVIDIA 驱动参数、显卡驱动下载、分辨率切换、ACE 优化、修复虚拟化、CPU 核心调度、强开 FSR4.0、电源计划 |
| 灵敏度调校 | 测、练、算三合一：按测试推荐灵敏度，瞄准训练，跨游戏换算，可从游戏配置直接读出当前值 |
| 音效增强 | 耳机 EQ 均衡器，低音 / 高音 / 清晰度 / 环境 / 环绕五类音效，支持动态增强与预设分享 |
| 玩家社区 | 音效预设、ICC 滤镜、改枪码与准星的配置广场，支持点赞、评论与一键导入 |
| 系统优化与调校 | 基础性能、游戏与调度、后台与服务、隐私防护、延迟优化、计划任务精调、个性化调整、服务批量管理，全部操作可回滚，支持系统还原点 |

详细介绍见官网 https://1utool.cn/ 。
